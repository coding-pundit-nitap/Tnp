## Getting Started

### Step 1: Create Your Account

1. Go to home page
2. Click **"Register"** button
3. Select **"Student"** role
4. Fill in the form:
   ```
   Name: [Your Full Name]
   Email: [Your college email]
   Password: [Strong password - at least 6 chars]
   ```
5. Click **"Register"**
6. You'll be redirected to login page
7. Login with your email and password

### Step 2: Complete Your Profile

After login, you'll see **"Complete Your Profile"** message.

Click **"Edit Profile"** and fill in:

- **Branch**: Select your branch (CSE, IT, ME, etc.)
- **Year**: Select your year (1st, 2nd, 3rd, or 4th)
- **CGPA**: Enter your current CGPA (0.0 - 10.0)

**Why does this matter?** Companies use this to filter candidates. Higher CGPA looks better!

## Uploading Your Resume

### Why Upload Your Resume?

- Companies can see your **skills** automatically extracted
- System calculates **match score** with each job
- More information = Higher chance of selection
- Shows you're serious about placement

### How to Upload

**Location:** Student Dashboard → My Resume

1. Click **"Upload Resume"**
2. Select PDF file from your computer
3. File must be:
   - ✅ PDF format only
   - ✅ Less than 5MB
   - ✅ 1-2 pages (recommended)
4. Click **"Upload"**
5. System automatically parses your resume

### What the System Extracts

After upload, you'll see:

#### **Skills Detected**

- Programming languages (Python, Java, C++, etc.)
- Frameworks (React, Django, Spring, etc.)
- Tools (Git, Docker, etc.)

#### **Education**

- Degree level (B.Tech, M.Tech, etc.)
- Field of study (Computer Science, Mechanical, etc.)
- Institution name

#### **CGPA from Resume**

- If mentioned in your resume, system reads it
- Used for eligibility checking

#### **Keywords**

- Important words from your resume
- Used to match with job requirements

### Resume Tips

**DO:**

- ✅ Mention all skills you have
- ✅ Include programming languages
- ✅ List frameworks and tools
- ✅ Add your CGPA clearly
- ✅ Keep it well-formatted
- ✅ Use common keywords

**DON'T:**

- ❌ Use fancy fonts or colors
- ❌ Make it longer than 2 pages
- ❌ Use scanned/blurry images
- ❌ Hide your CGPA if it's good
- ❌ Use jargon companies won't understand

### Example Resume Section (What helps)

```
SKILLS
Programming Languages: Python, Java, C++, JavaScript
Web Frameworks: Django, Flask, React
Databases: MySQL, MongoDB, PostgreSQL
Tools: Git, Docker, Linux, VS Code
Other: REST APIs, Machine Learning basics

EDUCATION
B.Tech in Computer Science
NIT Andhra Pradesh
CGPA: 7.8 / 10

PROJECTS
- Student Management System (Python)
- E-commerce Website (Django, React)
- COVID-19 Tracker (JavaScript)
```

### What Gets Extracted

From resume above, system will extract:

```
Skills: Python, Java, C++, JavaScript, Django, Flask, React, MySQL, MongoDB, PostgreSQL
CGPA: 7.8
Education: B.Tech, Computer Science, NIT Andhra Pradesh
Keywords: E-commerce, Website, APIs, Machine Learning
```

## Applying to Jobs

### Eligibility Check

Before applying, system checks:

1. **CGPA Match**
   - Your CGPA ≥ Job's minimum CGPA
   - ✅ If yes → You're eligible
   - ❌ If no → Application rejected automatically

2. **Branch Match**
   - Your branch in job's allowed branches
   - ✅ If yes → You're eligible
   - ❌ If no → Application rejected automatically

3. **Year Match**
   - Your year in job's allowed years
   - ✅ If yes → You're eligible
   - ❌ If no → Application rejected automatically

4. **Skill Match**
   - Your resume skills vs job requirements
   - Get a score (0-100%)

### How to Apply

**Click "Apply" button**

```
┌─────────────────────────────────────────┐
│ Checking eligibility...                │
├─────────────────────────────────────────┤
│ ┌─▶ CGPA Check... ✅ PASS               │
│ ├─▶ Branch Check... ✅ PASS             │
│ ├─▶ Year Check... ✅ PASS               │
│ └─▶ Skill Match... ✅ 78%               │
├─────────────────────────────────────────┤
│ Overall: ELIGIBLE                       │
│                                        │
│ [CONFIRM APPLICATION]                   │
└─────────────────────────────────────────┘
```

**If Eligible:**

- Click "Confirm Application"
- You'll see **"Application Submitted!"**
- Job appears in your Applications list

**If Not Eligible:**

- See which criteria you didn't meet
- You can try other jobs
- Or improve your CGPA and apply again later

### Application Status

After applying, your application status shows:

| Status             | Meaning                             |
| ------------------ | ----------------------------------- |
| 🔵 **Applied**     | Recruiter hasn't reviewed yet       |
| 🟡 **Shortlisted** | Recruiter liked you!                |
| 🔴 **Rejected**    | Not selected                        |
| 🟢 **Selected**    | Passed interview, waiting for offer |
| 💎 **Offered**     | Job offer received                  |

## Interview Process (For Students)

### When You're Shortlisted

You'll see: **Status Changed to "Shortlisted"** ✅

**Next Step:** Recruiter schedules your interview

### Interview Details

When recruiter schedules interview, you'll see:

```
📅 INTERVIEW SCHEDULED

Interview Details:
├─ Round: Technical Round 1
├─ Date: February 10, 2026
├─ Time: 10:00 AM
├─ Duration: 1 hour
├─ Location: Virtual (Zoom link: ...)
├─ Interviewer: John Smith
└─ Topics: Data Structures, Algorithms

Interview Tips:
✓ Join 5 mins early
✓ Test your audio/video
✓ Have your resume nearby
✓ Write down questions
```

### Interview Rounds

Most companies have multiple rounds:

**Round 1: Technical**

- Programming problems
- Data structures
- System design
- Technical questions

**Round 2: Technical (if passed)**

- Deeper technical questions
- Real project discussion
- Problem solving

**Round 3: HR**

- Why this company?
- Salary expectations
- Background questions
- Personality fit

### After Interview

Recruiter updates result:

```
Interview Result:
├─ Round: Technical Round 1
├─ Result: PASSED ✅
├─ Score: 85/100
├─ Feedback: "Great problem solving! Join next round."
└─ Next: HR Round scheduled for Feb 14
```

### If You Pass All Rounds

**Next Status:** Selected 🟢

Recruiter prepares job offer!

## Job Offers

### Receiving an Offer

Once selected, recruiter sends you an offer:

```
💎 JOB OFFER RECEIVED

Offer Details:
├─ Position: Senior Software Engineer
├─ Company: ABC Tech Solutions
├─ Location: Bangalore
├─ Final CTC: 8 Lakhs per year
├─ Joining Date: June 1, 2026
├─ Valid Until: February 20, 2026
│
└─ [ACCEPT OFFER] [DECLINE OFFER]
```

### Accept vs Decline

**Click "ACCEPT"** if:

- ✅ You like the company
- ✅ Salary is acceptable
- ✅ You're confident about the job
- ✅ You can join on the given date

**Click "DECLINE"** if:

- ❌ You have a better offer
- ❌ You need more time to think
- ❌ Something doesn't feel right
- ❌ You have personal reasons

**Important:** Once accepted, you're committed to this company!

### Offer Status

After accepting:

```
Status: Offer Accepted ✅

Your placement is finalized!
Congratulations on getting placed! 🎉
```

## Tips & Tricks

### 💡 Smart Application Strategy

1. **Upload resume early**
   - Don't wait till companies arrive
   - More time for skill matching

2. **Apply to multiple jobs**
   - Don't put all hopes on one
   - Try similar job roles

3. **Improve your CGPA**
   - Many jobs have CGPA cutoff
   - Every 0.1 point helps
   - Update it immediately

4. **Add diverse skills**
   - Both technical (Python, Java) and soft skills
   - Problem solving, Team work
   - Leadership, Communication

### 🎯 Increase Your Match Score

**Match score = how well your resume matches the job**

To improve:

- ✅ Add relevant skills to resume
- ✅ Mention frameworks you've used
- ✅ Include projects using those tech
- ✅ Use common keywords from job description

### ⏰ Interview Preparation

1. **Review your resume**
   - Be ready to discuss projects
   - Explain your role clearly

2. **Learn about company**
   - What they do
   - Tech they use
   - Recent news/updates

3. **Practice coding**
   - LeetCode problems
   - HackerRank challenges
   - Data structures & algorithms

4. **Mock interviews**
   - Practice with friends
   - Record yourself
   - Get feedback

### 📱 Check Regularly

- Check dashboard **2-3 times a week**
- Receive interview notifications immediately
- Don't miss interview schedule!

### 🤝 Be Professional

- Respond to recruiter messages promptly
- Keep email professional
- Be on time for interviews
- Send thank you emails after interview

## Troubleshooting

### Q: Can't login?

**Solution:**

1. Check email/password is correct
2. Password is case-sensitive
3. Try "Forgot Password" link
4. Clear browser cookies
5. Try different browser

### Q: Resume upload failed?

**Solution:**

1. Check file is PDF format
2. File size < 5MB
3. Try re-uploading
4. Use different browser
5. Contact admin if persistent

### Q: Application got rejected automatically?

**Reason:**

- Your CGPA < job's minimum CGPA
- Your branch not in allowed list
- Your year not in allowed years

**Solution:**

- Apply to jobs matching your criteria
- Improve CGPA and try again later
- Look for jobs with lower cutoff

### Q: Missing notifications?

**Solution:**

1. Check notification settings
2. Check spam/promotions folder
3. Check dashboard regularly
4. Ask recruiter to resend details

### Q: Can't withdraw application?

**Reason:** Application is shortlisted or further stage

**Solution:**

- Contact recruiter directly
- Explain your reason
- They can withdraw it

### Q: Interview link not working?

**Solution:**

1. Try link in different browser
2. Copy-paste link carefully (no extra spaces)
3. Contact recruiter for new link
4. Join 10 minutes early to test

### Q: Did badly in interview?

**What to do:**

1. Email recruiter
2. Ask for feedback
3. Explain your situation (if relevant)
4. Sometimes they give second chance
5. Learn and apply to other companies

## Important Notes

### Security & Privacy

✅ **Your data is safe**

- Only recruiters you apply to see your resume
- Your CGPA is visible only to companies with relevant jobs
- Admin can see aggregated data (no personal details)

### Frequently Asked Questions

**Q: Can I apply to same job twice?**
A: No, system allows only one application per job. You can withdraw and re-apply.

**Q: What if I don't get placed?**
A: Keep applying! Process continues throughout the year. More companies come later.

**Q: Can I move to different branch/year?**
A: No, you must contact admin. It requires database change.

**Q: What if offer expires?**
A: Recruiter usually extends if asked. Contact them immediately.

**Q: Can I accept multiple offers?**
A: Technically yes, but ethically no. Choose best offer and decline others.
