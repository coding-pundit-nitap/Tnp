## Posting a Job

### Create a New Job Posting

#### Step-by-Step:

1. **Open Jobs Section**
   - Click "My Jobs" in menu
   - **You see:** Your job postings list
   - Click: "[Post New Job]" button

2. **Fill Basic Information**

   **Job Title** (required)

   ```
   Examples: Web Developer, Data Analyst, DevOps Engineer
   Tips: Be specific, avoid abbreviations
   ✅ "Senior Java Backend Developer"
   ❌ "Engineer"
   ```

   **Job Category** (required)

   ```
   Choose: Development, Data, Infrastructure, Sales, HR, etc.
   ```

   **Number of Positions** (required)

   ```
   Enter: How many students will you hire?
   Range: 1-50
   ```

3. **Add Job Description**

   **Job Description** (required)

   ```
   Write 3-5 paragraphs about:
   - What will the student do?
   - What projects will they work on?
   - Day-to-day responsibilities

   Example:
   "As a Web Developer, you will:
   - Develop responsive web applications using React
   - Build RESTful APIs with Node.js
   - Optimize database queries with MongoDB
   - Participate in code reviews and testing
   - Collaborate with other developers and product team"
   ```

   **Responsibilities** (required)

   ```
   List key responsibilities (bullet points):
   - Develop features using latest technologies
   - Maintain code quality and documentation
   - Participate in team meetings
   - Debug and fix issues
   ```

4. **Set Location Details**

   **Job Location** (required)

   ```
   Options: Remote, On-site, Hybrid

   If On-site:
   City: Bangalore, Mumbai, Delhi, etc.
   Office Address: (optional)
   ```

5. **Set Salary Information**

   **Expected CTC** (Crores/Lakhs)

   ```
   Format: 5 Lakhs, 10 Lakhs, 1 Crore, etc.
   Tips: Be realistic, helps filter candidates
   ```

   **Salary Components** (optional)

   ```
   Base Salary: 3.5 Lakhs
   Bonus: 1 Lakh
   Benefits: Health Insurance, Meals, etc.
   ```

   **Internship Stipend** (if internship)

   ```
   Range: ₹500/day to ₹2,000/day
   ```

6. **Set Required Qualifications**

   **Minimum CGPA** (required)

   ```
   Enter: 6.0, 6.5, 7.0, 7.5, 8.0, etc.
   Note: Students below this auto-rejected
   Tip: Set reasonable - too high = few applicants
   ```

   **Preferred Branches** (required)

   ```
   Select multiple: CSE, IT, ECE, ME, etc.
   ✅ Accepts students from selected branches only
   Note: Other branches can't apply
   ```

   **Preferred Year** (required)

   ```
   Select: 3rd, 4th, or both
   ✓ 3rd Year: No previous placements usually
   ✓ 4th Year: More experienced
   ```

   **Preferred CGPA** (optional)

   ```
   Sometimes differ from minimum
   Example:
   Minimum: 6.0 (eligibility)
   Preferred: 7.0 (ideal candidate)
   ```

7. **Add Required Skills**

   **Primary Skills** (required)

   ```
   Type skills and add: Python, Java, React, etc.
   Format: Press Enter to add multiple
   Examples:
   - Backend: Java, Spring Boot, PostgreSQL
   - Frontend: React, JavaScript, CSS
   - DevOps: Docker, Kubernetes, AWS
   ```

   **Secondary Skills** (optional)

   ```
   Nice-to-have skills:
   - Git, Linux, Unit Testing, etc.
   ```

8. **Set Interview Details** (optional)

   **Interview Type**

   ```
   Online (Zoom/Teams/etc.)
   Phone Screen
   On-site visit
   ```

   **Number of Rounds**

   ```
   1-3 rounds typical:
   Round 1: Technical
   Round 2: Technical + HR
   Round 3: Final (Director/Head)
   ```

   **Estimated Timeline**

   ```
   When will interviews happen?
   Within 10 days? 2 weeks? 1 month?
   ```

9. **Set Job Duration** (if intern)

   **Start Date**
   - When internship begins

   **Duration**
   - How long: 2 months, 3 months, 6 months

10. **Review & Post**
    - Check all information one more time
    - Click "[Publish Job]"
    - **Result:**
      ```
      ✅ Job successfully posted!
      📧 All students receive notification
      📊 Job appears in student job list
      ```

### Shortlist Candidates

**What is Shortlisting?**

- You select students to interview
- Student gets notification "You've been shortlisted!"
- You can schedule interview with them

#### How to Shortlist:

1. **From Application List**
   - Find student you want to interview
   - Click "[Shortlist]" button
   - **Result:** Status changes to "Shortlisted"

2. **From Student Detail Page**
   - View individual student profile
   - Click "[Shortlist Candidate]" button
   - Confirmation popup appears
   - Click "Yes"
   - **Result:** Student status updates

3. **Bulk Shortlist** (if available)
   - Select multiple students (checkboxes)
   - Click "Shortlist Selected"
   - All marked students shortlisted at once

### Reject Candidates

**When to Reject:**

- Doesn't meet minimum qualifications
- Skills don't match
- You've filled all positions
- Student not a good cultural fit
- You want to focus on other candidates

#### How to Reject:

1. **From Application List**
   - Click on student
   - Click "[Reject]" button
   - **Optional:** Add rejection reason

2. **Add Rejection Notes**
   - Field: "Rejection Reason"
   - Examples:
     ```
     "Skills don't match job requirements"
     "CGPA below minimum threshold"
     "Position filled with another candidate"
     "Not a good fit for this role"
     ```
   - Click "Confirm Rejection"
   - **Result:** Student sees rejection notification

3. **Bulk Reject**
   - Select students you want to reject
   - Click "Reject Selected"
   - Enter reason
   - All marked students rejected

   ```
   Show only: Above 7.5
   ```

5. **Sort Results**
   ```
   Sort by:
   - Match Score (Highest first)
   - CGPA (Highest first)

   - Name (A-Z)
   ```

## Scheduling & Conducting Interviews

### Schedule Interview

#### Step-by-Step:

1. **Go to Application**
   - View shortlisted student
   - Click "[Schedule Interview]"
   - Form appears

2. **Select Interview Round**

   ```
   Round 1: Technical (Problem solving, coding)
   Round 2: Technical + HR (Skills + communication)
   Round 3: Final (Director/Head interview)
   ```

3. **Set Interview Details**

   **Interview Date**
   - Click calendar icon
   - Select future date
   - **Tip:** Give students 3-5 days notice

   **Interview Time**
   - Set: 10:00 AM, 2:30 PM, 4:00 PM, etc.
   - **Tip:** Schedule in working hours

   **Duration**
   - 30-45 min for coding round
   - 60-90 min for full interview
   - 30 min for HR round

4. **Interview Medium**

   **Virtual (Recommended)**
   - Select: Zoom, Google Meet, Teams
   - System sends meeting link to student
   - Link appears on their dashboard

   **On-site**
   - Enter office address
   - Provide directions/parking info

5. **Interview Notes**

   ```
   Optional field:
   - What topics to focus on
   - What to prepare
   - Any special instructions

   Example:
   "This is technical round. Be prepared for
   coding problems on arrays, strings, and trees.
   Bring problem-solving mindset!"
   ```

6. **Send Interview Details**
   - Click "[Send Interview Notification]"
   - **Result:**
     ```
     ✅ Email sent to student
     ✅ Interview shows in their dashboard
     ✅ Calendar invite sent
     ✅ Meeting link (if virtual) provided
     ```

### Conduct Interview

**During Interview:**

1. **Start Interview Call** (at scheduled time)
   - Join meeting link 5 minutes early
   - Test audio/video
   - Greet student professionally

2. **Introduction** (5 minutes)
   - Introduce yourself
   - Explain interview structure
   - "This round we'll focus on technical skills..."

3. **Ask Questions** (25 minutes)

   ```
   Sample Questions:

   Technical:
   - "Explain your project experience"
   - "How would you solve this problem?"
   - "What's your approach to debugging?"
   - "Explain a difficult concept you learned"

   Communication:
   - "Why interested in this role?"
   - "What are your strengths?"
   - "How do you handle challenges?"
   - "Questions for us?"
   ```

4. **Take Notes**
   - Keep interview notepad ready
   - Note key points:
     - Strengths demonstrated
     - Weaknesses observed
     - Quality of answers
     - Communication ability
     - Technical depth
   - Don't distract student while they're thinking

5. **Conclude Interview** (5 minutes)
   - "Thank you for your time"
   - "We'll inform you of results soon"
   - "Any final questions?"

### Record Interview Results

#### Step-by-Step:

1. **Go to Application** (After interview)
   - Find student you interviewed
   - Click "[Record Interview Result]"

2. **Fill Interview Result Form**

   **Interview Status**

   ```
   ☐ PASSED - Move to next round/offer
   ☐ FAILED - Don't proceed
   ☐ HOLD - Undecided, might schedule again
   ```

3. **Provide Score**

   ```
   Rate: 0-100

   50-60: Needs improvement
   60-70: Acceptable
   70-80: Good
   80-90: Excellent
   90-100: Outstanding
   ```

4. **Add Feedback**

   ```
   Write 2-3 sentences:
   "Strong problem-solving skills, solved complex
   algorithm correctly. Communication could improve.
   Good cultural fit for the team."
   ```

5. **Technical Comments** (optional)

   ```
   Help remember details:
   - Solved 1st problem well
   - Struggled with second problem
   - Good knowledge of databases
   - Needs to improve speed
   ```

6. **Next Steps**
   - If PASSED: "[Schedule Next Round]" option
   - If FAILED: "[Send Rejection]" option
   - If HOLD: "[Re-interview Later]" option

7. **Submit Result**
   - Click "[Save Result]"
   - **Result:**
     ```
     ✅ Result saved
     ✅ Status updates in system
     ✅ Student notifications sent
     ```

### Multi-Round Interviews

**For 3-Round Interview Process:**

```
Round 1: Technical (Problem Solving)
         ↓ PASSED
Round 2: Advanced Technical + HR (Skills + Culture)
         ↓ PASSED
Round 3: Final (Director Interview)
         ↓ PASSED
Offer: Send job offer
```

**Scheduling:**

1. After Round 1 PASSED → Schedule Round 2 (3-5 days later)
2. After Round 2 PASSED → Schedule Round 3 (5-7 days later)
3. After Round 3 PASSED → Send offer

## Creating & Sending Offers

### Send Job Offer

#### Step-by-Step:

1. **After Final Interview**
   - Student passed all rounds
   - Go to application
   - Click "[Create Offer]" or "[Send Offer]"

2. **Fill Offer Details**

   **CTC (Cost to Company)**

   ```
   Enter: 7 lakhs, 1 crore, etc.
   This can be different from job posting!
   You can negotiate based on performance.
   ```

   **Salary Components**

   ```
   Base Salary: 4 Lakhs
   Bonus/Incentive: 1 Lakh
   Stocks (optional): 2 Lakhs (vests over 4 years)
   Benefits (optional): Health insurance, meals
   ```

3. **Set Joining Details**

   **Offer Valid Until**

   ```
   Date format: Feb 28, 2026
   Students must accept before this date
   Typical: Offer valid for 15-30 days
   ```

   **Expected Joining Date**

   ```
   When should student join?
   Example: June 1, 2026
   Or: Post graduation
   ```

   **Internship Duration** (if applicable)

   ```
   2 months, 3 months, 6 months, etc.
   ```

4. **Additional Terms** (optional)

   ```
   Performance-based bonus:
   "Bonus up to 1 Lakh based on performance at 6 months"

   Growth path:
   "Clear path to Senior Engineer within 2 years"

   Training:
   "Company-sponsored training in cloud technologies"
   ```

5. **Document Attachment**
   - Upload offer letter PDF (if you have one)
   - Digital version for student records

6. **Send Offer**
   - Click "[Send Offer]"
   - **Result:**
     ```
     ✅ Email sent to student
     ✅ Offer appears in student dashboard
     ✅ Student can accept/decline
     ✅ Acceptance tracked automatically
     ```

### Offer Status Tracking

**Offer States:**

```
1. Offer Sent
   └─→ Waiting for student response

2. Offer Accepted ✅
   └─→ Student accepted!
       Place in "Placements" section

3. Offer Declined ❌
   └─→ Student declined
       Can reach out to next candidate

4. Offer Expired ⏰
   └─→ Student didn't respond by deadline
       Can send to next candidate
```

### Manage Multiple Offers

**If you have multiple positions:**

1. **Track Open Positions**
   - View: How many positions filled?
   - View: How many open yet?

2. **Send Offers in Sequence**
   - First rounds: Best candidates
   - Second candidate: If first declines
   - Third candidate: Backup option

3. **Keep Candidates Informed**
   - Let them know you're deciding
   - Provide timeline: "Decision by Feb 20"
   - Stay professional and respectful

## Tips & Best Practices

### 👍 How to Get Great Candidates

✅ **Write Clear Job Postings**

- Don't use vague descriptions
- Explain what student will actually do
- List all required skills
- Be realistic about salary

✅ **Set Reasonable Requirements**

```
Good: CGPA 6.5+, Java, Spring Boot
Bad: CGPA 8.5+, 5 years experience (for students!)
```

✅ **Respond Quickly**

- Schedule interviews within 3-5 days
- Provide interview feedback
- Send offer within 1 week of last round
- Students appreciate quick decisions

✅ **Be Respectful**

- Thank students for their time
- Provide constructive feedback if rejected
- Honor promised timelines
- Keep communication professional

✅ **Provide Clear Interview Process**

- Explain what each round covers
- Provide preparation tips
- Share expected timeline
- Explain further steps

### 👎 Common Mistakes to Avoid

❌ **Don't Post Vague Jobs**

- "We're looking for talented engineers"
- Students won't know what you want

❌ **Don't Set Unrealistic Requirements**

- Wanting 10 years experience from graduates
- Requiring skills not relevant to job

❌ **Don't Delay Interviews**

- Shortlist on Day 1, interview on Day 14
- Delays frustrate candidates

❌ **Don't Ignore Applications**

- Students apply, hear nothing for 2 weeks
- They'll assume you're not interested

❌ **Don't Change Requirements Mid-way**

- "We initially said CGPA 6.5, now want 7.5"
- Seems unfair to candidates

### ⭐ Interview Tips

**Before Interview:**

- ✅ Review candidate resume
- ✅ Prepare questions (don't off-the-cuff)
- ✅ Know your job requirements
- ✅ Test technology (Zoom/Teams)
- ✅ Start 5 minutes early

**During Interview:**

- ✅ Make candidate comfortable
- ✅ Listen more than you talk
- ✅ Take notes (don't rely on memory)
- ✅ Be fair to all candidates
- ✅ Ask same questions to all (consistency)

**After Interview:**

- ✅ Record decision within 24 hours
- ✅ Provide feedback to candidate
- ✅ Schedule next round within 3 days
- ✅ Inform of rejection promptly

## Troubleshooting

### Issue 1: "Students Can't See My Job"

**Possible Causes:**

1. Job status is "Draft" (not published)
2. Job doesn't meet search criteria
3. CGPA filter too high
4. Wrong branches selected

**Solutions:**

- ✅ Check job status is "Published"
- ✅ Try different CGPA requirement (try 6.0)
- ✅ Ensure right branches selected
- ✅ Check job posting date (shouldn't be in future)
- ✅ Promote publicly (ask admin to feature)

### Issue 2: "Very Few Applications"

**Possible Causes:**

1. Job requirements too strict
2. Salary too low compared to market
3. Job not interesting/clear
4. Posting time (not enough students browsing)

**Solutions:**

- ✅ Lower CGPA requirement slightly
- ✅ Increase salary to competitive level
- ✅ Rewrite job description (make exciting)
- ✅ Highlight learning opportunity
- ✅ Ask admin to feature job on homepage
- ✅ Consider internship before full-time

### Issue 3: "Can't Find Application"

**Solution:**

- Click "My Jobs" → Select job
- Use search/filter to find student
- Try searching by email: student@college.ac.in

### Issue 4: "Interview Link Not Sent"

**Possible Causes:**

1. Link copied incorrectly
2. Email didn't send (check spam)
3. Interview time hasn't arrived yet

**Solutions:**

- ✅ Check student email (inbox + spam)
- ✅ Copy-paste fresh link (avoid typos)
- ✅ Test link before sending
- ✅ Send SMS reminder day before
- ✅ Provide backup dial-in number

### Issue 5: "Can't Bulk Import Candidates"

**Note:** System doesn't support bulk import currently

**Workaround:**

- Recruiters: Post job, students apply naturally
- If 100+ applications: Ask admin for help filtering

### Issue 6: "Salary Data Not Showing in Reports"

**Check:**

- ✅ Did you fill salary field?
- ✅ Refresh page (F5)
- ✅ Log out and log back in

### Issue 7: "Student Applied But I Don't See"

**Check:**

- ✅ Go to correct job posting
- ✅ Scroll down in applications list
- ✅ Refresh page
- ✅ Check filters (maybe accidentally filtered)

### Issue 8: "Interview Status Stuck"

**If application stays "Interview" without result:**

2. Check if interview result was recorded
3. If not: Click "Record Interview Result"
